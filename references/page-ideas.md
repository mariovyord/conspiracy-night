- Ensure category balance
- Include variety of danger/absurdity levels

## Topic Development Checklist

When creating a new topic:

1. **Research Phase**
   - [ ] Understand the conspiracy theory thoroughly
   - [ ] Find multiple sources (believers and skeptics)
   - [ ] Identify key claims and evidence cited
   - [ ] Research legitimate concerns it reflects

2. **Planning Phase**
   - [ ] Choose appropriate category
   - [ ] Assign danger/absurdity/rabbit hole scores
   - [ ] Determine required disclaimer type
   - [ ] Identify pop culture references

3. **Writing Phase**
   - [ ] Write compelling introduction
   - [ ] Present believer claims fairly
   - [ ] Explain psychological appeal
   - [ ] Provide skeptical counterarguments
   - [ ] Add pop culture references
   - [ ] Create discussion questions
   - [ ] Include appropriate disclaimer

4. **Review Phase**
   - [ ] Fact-check claims and attributions
   - [ ] Verify tone is balanced
   - [ ] Confirm safety compliance
   - [ ] Test readability
   - [ ] Preview in browser

5. **Publishing Phase**
   - [ ] Add frontmatter metadata
   - [ ] Upload any images
   - [ ] Test links
   - [ ] Check mobile layout
   - [ ] Share on social media
